# Siath OS — Comandos Originais (thais-sh)

Shell `thais-sh` não é bash. Sintaxe própria, comandos em grego transliterado.

## Básicos
- `horasis [caminho] [-l]` — ver/listar (ls)
- `metabasis <caminho>` — mover-se (cd)
- `ktisis <nome> [-d]` — criar (touch/mkdir)
- `anairesis <nome>` — remover (rm)
- `graphe <arquivo>` — ler (cat)
- `praxia <bin> [args]` — executar (exec)

## Sistema Ancap Implícito
- `synallagma list` — listar contratos voluntários
- `synallagma start <nome>` / `stop` — gerenciar sem coerção
- `kinesis` — processos em movimento (ps)
- `aisthesis list` — dispositivos/sentidos
- `emporion search` / `install <pkg>` — mercado
- `agora sync` — federar repos (git-like)
- `nomos <arquivo>` — editar leis/configs

## Easter Eggs Austríacos/Thaís
- `thais` — ode à criadora
- `op3n` / `op3ny` — discord/github
- `menger`, `hayek`, `rothbard`, `mises` — citações
- `praxia` — homenagem à praxeologia

Todos têm alias POSIX oculto (`ls` → `horasis`) mas desencorajado.
